# Dataset

This project uses the **Olist Brazilian E-Commerce Public Dataset**.

Due to GitHub repository size limitations and dataset licensing, the original data files are not included in this repository.

You can download the dataset from Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The SQLite database (`olist.db`) used in this project was created by importing the original CSV files into DBeaver.
